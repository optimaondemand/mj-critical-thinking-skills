📍 Why this page exists
Every assignment you turn in for this course will be a file you create — usually a Word document or PowerPoint, sometimes Excel. This page is your always-on cheat sheet for setting up your Microsoft 365 account, organizing your files in OneDrive, naming them correctly, and submitting them through Canvas. Come back here any time you're not sure how to do something with files.
PART 1
Sign in to your Optima Microsoft 365 account

Every Optima student has a free school Microsoft 365 account. Use this account — not a personal Microsoft, Google, or Apple account — for every assignment in this class.

  1. Go to office.com (or open Word/PowerPoint/Excel on your computer).
  2. Click Sign in.
  3. Enter your school email address (the one your teacher set up for you with Optima).
  4. Enter your password. If you don't know it or it isn't working, message your teacher in Canvas — do not create a personal Microsoft account as a workaround.

Why this matters: your Optima account gives you free desktop and web versions of Word, PowerPoint, Excel, and OneDrive — PLUS your work is automatically backed up.

PART 2
Set up your OneDrive course folder (your "digital binder")

Just like you'd use a physical binder for school, OneDrive is where you keep all your class files organized. You only need to set this up once.

  1. Sign in to OneDrive at onedrive.com (or open the OneDrive app).
  2. Click + New → Folder. Name it Optima
  3. Inside the Optima folder, create a subfolder named Critical Thinking
  4. Inside that, create a subfolder named MJCRT_2025-26 (the course code + school year)
  5. This last folder is where EVERY assignment for this class goes. That's it.
Your folder structure should look like this:
OneDrive (School Account) └── Optima/ ├── Critical Thinking/ │ └── MJCRT_2025-26/ <-- all assignments go here ├── ELA/ ├── Math/ ├── History/ └── Science/

Make a top-level subject folder for each of your other classes too. Once it's set up, you never have to think about it again.

PART 3
The Optima File Naming Rule

Every file you turn in for any Optima class follows the same name pattern. This makes it easy for you AND your teacher to find your work later.

THE PATTERN
LastName_FirstName_AssignmentName_CourseCode
LastName _ FirstName _ AssignmentName _ MJCRT
LastNameYour last name, capitalized, no spaces. FirstNameYour first name, capitalized, no spaces. AssignmentNameA short name for the assignment (your teacher will give it in each assignment description). MJCRTThe course code for this class. MJCRT = M/J Critical Thinking. _Underscores between each part. NO spaces, NO dashes.
✓ Good examples
Smith_Jane_TimeManagement_MJCRT.docx
Patel_Arjun_CookieJar_MJCRT.docx
Wong_Kai_FieldBiology_MJCRT.docx
✗ Don't do this
My homework.docx   (no name, no course, no assignment)
jane smith time mgmt.docx   (spaces, lowercase, abbreviation)
Untitled (3).docx   (forgot to rename it)
⚠️ For multi-draft assignments
Add _Draft1, _Draft2, and _Final to your file name. Save each draft as a separate file (File → Save As). Never overwrite an old draft — your teacher needs to see your revision history.
Smith_Jane_GoodLifeCapstone_MJCRT_Draft1.docx
Smith_Jane_GoodLifeCapstone_MJCRT_Draft2.docx
Smith_Jane_GoodLifeCapstone_MJCRT_Final.docx
PART 4
Which M365 tool for which kind of work?

All assignments in this class use Microsoft 365 tools — not Google Docs, Slides, or Sheets. If you're not sure which tool to use, this table will help.

If the assignment asks for… Use this M365 tool File ends in
Essay, reflection, written response, notes Word .docx
Presentation, slide deck, infographic-style visual PowerPoint .pptx
Data log, table, calculations, tracker (e.g., the Good Life Project) Excel .xlsx
A photo, screenshot, or scanned drawing Your phone camera or screenshot tool .jpg / .png
PART 5
Submitting via Canvas (the OneDrive tab)

When you've finished and named your file, here's how to turn it in.

  1. Make sure your file is saved in OneDrive (it should auto-save if you signed in correctly).
  2. In Canvas, open the assignment and click Start Assignment (or Submit Assignment).
  3. Click the OneDrive or Office 365 tab in the submission panel.
  4. Find your file in the list, click it, and click Submit.
  5. You'll see a confirmation that the file was submitted — if you don't, the submission didn't go through.

If your file is somehow not in OneDrive (you typed it in Word offline, etc.), use the File Upload tab instead and choose the file from your computer.

CHECKLIST
Before every submission, ask yourself…

☐  My file is in the right folder: Optima → Critical Thinking → MJCRT_2025-26.
☐  My file name follows the Optima File Naming Rule.
☐  I used the right M365 tool for what was asked (Word, PowerPoint, or Excel).
☐  I submitted through Canvas using the OneDrive tab.
☐  I saw the confirmation that the submission went through.
