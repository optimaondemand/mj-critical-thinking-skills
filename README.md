# M/J Critical Thinking Skills (Florida 1700100)

Interactive lesson pages for the Optima Academy Online M/J Critical Thinking Skills course, hosted on GitHub Pages and embedded in Canvas (course 24) via iframe.

- `module-1/` … `module-5/` — interactive lessons, section prefaces, and project intro pages
- `course-resources/` — persistent M365 setup & file organization guide
- `images/` — course images referenced by lessons

Graded items (assignments, VR activities, capstones) and module intro/outro survey quizzes are Canvas-native and are not stored here.
